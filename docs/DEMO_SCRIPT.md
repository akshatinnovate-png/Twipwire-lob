# Finals demo script (7 minutes plus Q&A)

**Before you walk on:** run `python scripts/preflight.py`. It must print `READY`. Then start `python scripts/cockpit.py`, open http://localhost:8765, and let it warm up for 10 seconds. The laptop should be on mains power, and no internet is needed. If the browser shows "engine offline", restart the server. The Evidence and Method sections still work from saved files.

| time | who | what is on screen | what to say |
|---|---|---|---|
| 0:00 | Saharsh | hero | "Order-book models don't crash when the market changes. They keep answering confidently and wrongly. We built a forecaster that notices first, says so, and recovers, with a false-alarm rate we can state in advance." |
| 0:40 | Saharsh | cockpit, synthetic, calm | Walk the windows. FORECAST shows ŷ ± q, the realised move and the calls. DETECTORS shows two Shiryaev–Roberts statistics against a threshold that fixes the false-alarm budget. POOL shows the experts. TELEMETRY shows coverage ≈ 90 % and p99 latency. |
| 1:30 | judge or Akshat | press **CONCEPT FLIP** | "The book looks identical; only its meaning reversed. A feature test like rolling KS cannot see this, because P(X) didn't move." Point at Monitor R rising and firing within a few hundred events. A regime head spawns, the band widens, the call rate drops, and coverage returns to 90 %. "That is degrading loudly." |
| 2:30 | judge | press **COVARIATE SHOCK** | Monitor F fires and Monitor R stays quiet: "harmless shift, so we widen the interval and don't touch the model." This is shift-type selectivity. |
| 3:10 | Akshat | source **AAPL (real)** | "This is real LOBSTER AAPL, event by event, walk-forward, with labels delayed h = 50 events." Press **CONCEPT FLIP**: "Now we reverse the real signal in the real label stream. P(X) is untouched by construction." |
| 4:00 | Akshat | Evidence section | Headline numbers, then the replays: the recurrence run (weights return to a frozen head when a regime comes back) and the rolling-KS triangles firing all over calm data. |
| 5:00 | Akshat | Method section | The four layers and what each guarantees. Spend about 30 seconds on the orthogonality window: "We changed Monitor R after Round 1 because the data showed the |residual| test has no power when R² ≈ 1 %." |
| 6:00 | Saharsh | `results/tables.md` | Commitments from the Round-1 abstract against what we measured, including where we fell short. |
