# Finals demo script (7 minutes plus Q&A)

## Before you walk on
1. `python scripts/preflight.py` must print `READY`.
2. `python demo.py` (or `python demo.py --source AAPL`). It checks everything, warms the engine and opens the browser on the cockpit. Wait for the terminal to print `ready` before taking questions on the demo.
3. Laptop on mains power. No internet is needed except for the optional BTC segment.
4. Optional BTC segment: about an hour before, run `python scripts/record_binance.py --minutes 45` on venue or hotspot Wi-Fi. `demo.py --source BTC` then starts live within seconds. If the Wi-Fi dies mid-demo, the cockpit switches to replaying that recording and the screen says **REPLAY**. Never present a replay as live.

**Stage keys (no mouse hunting):** `1` concept flip · `2` covariate shock · `3` both · `0` calm · `space` pause · `s` next source · `r` restart.

Synthetic mode pre-runs 20,000 calm events during warm-up. That matters: Monitor R tests the long-memory expert, which needs a settled history. `demo.py` waits for that automatically, so any key press after `ready` is safe (this is checked by `tests/test_cockpit.py`).
